# Explicit relationship verification

`DocumentVerifier.Verify(document, rules, policy)` checks caller-bound document relationships and returns review evidence plus optional reread requests. It does not execute OCR, alter values, infer a financial schema, or assert that consistent text is correct. A printed total may itself be wrong; contradictions retain every original reading.

Each `DocumentVerificationRule` references existing `DocumentBlockReference` values. `ExactText` compares complete block texts ordinally, preserving case, whitespace, units and punctuation. `DecimalSum` compares the sum of complete input block texts with the expected total, using an explicit `CultureName` (empty means invariant) and nonnegative absolute tolerance. It accepts decimal signs and separators, not currency symbols, grouping separators, exponents or numbers extracted from prose. Overflow and values requiring decimal precision rounding are unverifiable, never silently rounded into agreement. Use explicit field/label binding upstream; no learned selector is included.

The policy bounds admitted rules, total source references, unique reread requests and aggregate integer-covering rectangle pixels. Reports identify rules skipped by reference admission, truncated rule enumeration, and regions rejected for missing source, unknown/transformed coordinates, invalid geometry or exhausted budgets. Duplicate operands are rejected to prevent accidental double counting. Rereads require declared original-source structure coordinates; rotation and nonlinear unwarp remain review evidence without falsely claiming a source crop. Callers can submit admitted requests to their own bounded OCR workflow and retain the original report alongside alternatives.

`DocumentVerificationReport.ToJson()` uses source generation and retains raw text, source IDs, geometry, check reasons and skipped requests. Repeated failing rules share a unique request per source block. The API is deterministic infrastructure for roadmap experiment 4, not a trained verifier, automatic correction system, or measured accuracy improvement. Independent labeled evaluations must include documents whose printed totals are inconsistent.
